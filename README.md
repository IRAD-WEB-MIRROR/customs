# customs.iradgov.org

Mirror of the website of the **Customs Service of Irad** (Talas Customs Clearance Terminal):
[customs.iradgov.org](https://customs.iradgov.org/).

Pages in English, Iradi and Russian: notices, the tariff and duty calculator, border crossings, the Terminal, and the
rules for travellers. Texts and images belong to the Customs Service; questions about customs go to the Service, not
to the mirror.

Part of the [Irad Web Mirror](https://github.com/IRAD-WEB-MIRROR).
